# 题库格式

## 来源与合规

- 仓库：[ERRRC/xingcezhenti](https://github.com/ERRRC/xingcezhenti)
- 本地目录：`xingcezhenti-main`
- 仓库内未看到 LICENSE 文件，**不要把题库打包进 Skill、文章附件或网盘分享**；让读者自行从原仓库获取。
- 题目、答案、解析的版权归原仓库及其来源；本 Skill 只做本地解析和组卷。

题目记录数是按「每套卷的每个模块一篇」统计的出现次数，不是唯一题目数。同一道题会在不同省份/年份重复出现，去重按 `qid`。

## 目录

```text
xingcezhenti-main/
├── 01-政治理论/
├── 02-常识判断/
├── 03-言语理解与表达/
├── 04-数量关系/
├── 05-判断推理/
├── 06-资料分析/
└── 90-图片/
    ├── 题目图/
    └── 公式图/
```

每个模块目录下是一套卷一篇 `.md`，不是一题一篇。`90-图片` 不是题目模块，脚本会跳过。

## Frontmatter

每篇开头：

```yaml
---
类型: "真题"
试卷: "2016年423联考《行测》题（云南网友回忆版）"
地区: "云南"
年份: "2016"
模块: "言语理解与表达"
题数: "40"
来源: "tiku.db 原始题库（未蒸馏）"
---
```

脚本读取 `试卷`、`年份`、`地区`、`模块`；缺失时用文件名和目录名兜底。

## 题目块

普通模块：

```markdown
## 第 1 题　<sub>qid 1796080 · 逻辑填空</sub>

题干文字，可能包含 <p> 和 <img>。

- **A**. 选项一
- **B**. 选项二
- **C**. 选项三　✅
- **D**. 选项四

**答案**：C

**官方解析**

解析文字，可能包含公式图片。

---
```

资料分析：

```markdown
## 材料 1

材料文字和表格图片。

### 第 1 题　<sub>qid 2263114 · 综合</sub>

题干

- **A**. ...
...

**答案**：D

**官方解析**

...
```

解析规则：

- 题目标题匹配 `##` 或 `###` 的 `第 N 题`，`qid` 和题型从 `<sub>` 中取。
- 选项匹配 `- **A**. ...`，支持 A–E；`✅` 标记正确项，但答案以 `**答案**` 为准。
- 答案匹配 `**答案**：X`，可能是 `A`、`ABCD` 或文字。
- 解析从 `**官方解析**` 到下一个题目标题或文件末尾。
- 资料分析题自动附带最近一个 `## 材料 N` 到第一道小题之间的内容。
- 相同材料文字用内容哈希分组，避免同一材料在不同省份卷中重复输出。

## 已知边界

1. **判断题没有 A–D 选项**：原文用 `- （选项）[]` 占位，答案给 A/B。组卷时显示「判断题」，答案页把 A/B 映射为「正确/错误（原始答案 A/B）」。
2. **部分题有 5 个选项**：如陕西卷数量关系，选项到 E，脚本支持 A–E。
3. **题干和解析含 HTML**：`<p>`、`<img>` 原样保留；图片路径是相对原 Markdown 的 `../90-图片/...`，组卷时按输出目录重写。
4. **同一 qid 重复**：58,890 条记录只有 27,473 个不同 qid；默认按 qid 去重，保留最早一条。
5. **资料分析是一材多题**：材料只输出一次，后面跟同一材料的小题。
6. **图片跨盘符**：Windows 下输出目录和题库不在同一盘符时无法计算相对路径，脚本退回绝对路径；把输出放在题库同级目录可保持相对路径。

## 不做的事

- 不改写题干、选项、答案。
- 不按「考点」自动打标签；题库没有考点字段。
- 不预测分数、不押题、不承诺提分。
- 不把题库复制进 Skill 或对外分发。

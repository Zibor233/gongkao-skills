# 备注判定规则

备注是隐性条件最集中的字段（2027 简章 98.7% 非空）。规则的原则是：**能确定算硬条件，不能确定就算复核，绝不靠猜。**

## 一、处理顺序

1. 按 `。`、`；`、换行切句，保留原句。引用时整句引用，不改写。
2. 先跑硬条件：最低服务年限、应届/毕业年份、英语四六级、工作强度。
3. 再抽复核事项：性别表述、户籍/生源、证书、体检体能、政治考察。
4. 同一句命中多个类别时，各类别都记录，但同一「类别 + 原句」只记一次。

## 二、硬条件

| 类别 | 匹配表述 | 判定 |
|---|---|---|
| 最低服务年限 | 最低服务年限、最低服务期、服务年限、服务期 | 算出年限；考生不接受或超过可接受上限 → 不推荐 |
| 应届/毕业年份 | `20XX届`、应届、非应届 | 限具体年份且考生年份不符 → 不推荐；非应届明确时反向判断 |
| 英语四级 | 大学英语/英语/CET + 四级/CET4 | 要求且考生未通过 → 不推荐 |
| 英语六级 | 大学英语/英语/CET + 六级/CET6 | 要求且考生未通过 → 不推荐；「四级或六级」通过其一即可 |
| 工作强度 | 经常出差、长期出差、夜间值班、加班、高强度、野外作业、艰苦边远、高原、海岛、轮班、驻外、封闭管理 | 考生明确不接受 → 不推荐 |

## 三、复核事项

| 类别 | 匹配表述 | 为什么不能自动判 |
|---|---|---|
| 性别表述 | 男性、女性、适合男性、适合女性、限男性、限女性 | 「适合男性」不是绝对限制，实际执行口径由招录单位解释 |
| 户籍/生源 | 户籍、生源、户口 | 可能限本省、本市或本县，需核对考生具体户籍地 |
| 证书 | 法律职业资格、注册会计师、CPA、税务师、执业医师、执业药师、教师资格、计算机等级、专业八级、资格证书、职业资格、会计专业技术资格、注册建筑师、注册安全工程师 | 证书类别、等级、取得时间、是否要求主证都可能影响 |
| 体检体能 | 体能测评、体能测试、体检、视力、色盲、色弱、身高、体重、人民警察、警察体能 | 标准在公告附件，脚本无法读取 |
| 政治考察 | 政治考察、政审、政治审查 | 考察范围和结论由组织部门掌握 |

## 四、已知误判与处理

1. **四级主任科员 / 四级主办 / 四级调研员**：职级，不是英语四级。必须同一句出现「大学英语/英语/CET」才判英语。
2. **「不限户籍」**：句中出现「不限」时不标户籍复核，否则会把放开条件误报成限制。
3. **「男女不限」「性别不限」**：不标性别复核。
4. **「无最低服务年限」「不设服务期」**：不按服务年限限制处理。
5. **「非应届」**：先判断否定，再判断「应届」，否则会把非应届要求误判成应届要求。
6. **「应届毕业生」没有年份**：只要求应届身份，不要求具体年份；考生是应届即通过。
7. **「服务基层项目工作经历：无限制」**：不是要求服务经历，直接通过；同一句里的「无」不是「无经历」。
8. **「参照公务员法管理」**：说明单位性质，不是报考条件，不产生复核项。
9. **「体检标准参照……执行」**：仍列体检复核，但不判不推荐；标准需查公告。
10. **「以上」「以下」**：官方语境默认含本级。学历、年限解析按含本级处理。
11. **「优先」「同等条件下优先」**：不是硬门槛，不判不推荐；如需提示，写在复核说明里。
12. **备注为空或只有「无」**：不生成任何备注类结论。
13. **一条备注多个要求**：逐句判定，不要因为一句通过就放过另一句。
14. **「英语专业四级/八级」**：是英语专业证书，不是大学英语四六级；按证书复核，不按 CET4/CET6 硬判。

## 五、引用规则

- 复核依据必须是备注或专业列的原文片段，用「」包裹。
- 可以整句引用，不可以把两句拼成一句，不可以把「适合男性」改写成「仅限男性」。
- 找不到可引用原句时，写「字段原文为空，需人工确认」，不要编造依据。
- 专业大类复核引用「专业」列原句；其他复核引用「备注」原句。

## 六、红线

- 不输出上岸概率、竞争比、分数线预测。
- 不把「待复核」解释成「有希望」或「没戏」，只陈述需要确认的事项。
- 不替招录单位下结论；最终以电话答复和资格复审结果为准。
